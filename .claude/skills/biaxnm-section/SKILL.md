# 단면 조각 만들기

결과물은 `[section]` TOML 조각 하나다. 설계기준, 재료 강도, 하중은 이 skill 의 일이 아니다(`biaxnm-inputs`). 길이는 mm, 면적은 mm² 이다.

사용자에게 묻는 것은 AskUserQuestion 으로 한다(선택지가 있는 것은 선택지로). 입력에 없는 값은 추측하지 않는다. 호출한 쪽이 넘긴 **이미 아는 값**은 다시 묻지 않고 표로 보여 주기만 한다(응답을 기다리지 않는다). 모르는 것만 묻고, 사용자가 답한 값도 표로 보여 주기만 한다. 정보가 충분하면 질문 없이 조각을 낸다.

호출 시 "재계산" 이라고 알려 주면 5단계만 실행한다.

## 0. 스키마 읽기

이 문서 맨 아래 "부록. [section] 스키마"(도형 키, `holes`, `rebar_standard`, `bars`, `steel`, `tendons`)를 읽는다. 키 이름과 기본값을 기억에 의존하지 않는다.

## 1. typical 여부

| 구분 | shape | 필수 변수 (mm) |
|---|---|---|
| 콘크리트 | `rect` | width, height (선택: r 모서리 반지름) |
| | `circle` | r (반지름) |
| | `track` | length, width (length > width) |
| | `t_section` | bf (플랜지 폭), h (전체 높이), tf, tw |
| | `l_section` | width, height, tx (세로 다리 폭), ty (가로 다리 높이) |
| 구멍 | 위 도형 또는 꼭짓점 | 외곽선 안쪽에 완전히 들어가야 함. 중공 원형(말뚝)은 `circle` 구멍 |
| 형강 | `h_section` | d, bf, tw, tf |
| | `hollow_rect` | width, height, t |

typical 이면 2단계로, 아니면 꼭짓점 `[[x, y], ...]` 를 받는다(3개 이상, 자기 교차 불가). 도형 표에 없는 형상은 사용자에게 꼭짓점을 달라고 한다.

## 2. 변수 입력

해당 도형의 필수 변수 목록을 보여 주고 "자연어로 한 번에 적어 주세요"라고 요청한다(예: "폭 400, 높이 600"). 받은 값을 표로 되풀이한다.

- 좌표계는 `rect`, `t_section`, `l_section` 은 좌하단이 원점(x=0, y=0), `circle`, `track`, `h_section`, `hollow_rect` 는 중심 `cx, cy` 이다. 이후 철근, 형강, 긴장재 좌표는 모두 같은 원점을 쓴다.
- 형강과 PS강봉은 철근 다음 4단계에서 묻는다.

## 3. 철근

철근 좌표를 사용자가 말하게 하지 않는다. 아래를 묻는다.

1. **순피복** (콘크리트 표면에서 띠철근 바깥까지)과 **띠철근(나선철근) 직경**
2. **철근 간격** (중심 간 최대 간격) 과 **철근비** (총단면 대비 %). 둘 중 하나만 있어도 된다. 둘 다 정확히 맞출 수는 없다.
3. **철근 규격표** (`KS`, `ASTM`, `ASTM_SI`, `BS`). 사용자가 쓰는 호칭(D25 등)을 따르고, 모르면 `KS`.

철근 중심은 표면에서 `순피복 + 띠철근 직경 + 주철근 지름/2` 에 놓인다. 지름이 바뀌면 이 값도 바뀐다.

### 사각, 원형 단면: 스크립트로 후보 계산

`<PY>` 는 저장소에 `python/python.exe` 가 있으면 그것, 없으면 `python` 이다.

```
<PY> .claude/skills/biaxnm-section/layout.py rect   --width W --height H --cover C --tie T [--spacing S] [--ratio R] [--standard KS] [--sizes D19,D22,D25]
<PY> .claude/skills/biaxnm-section/layout.py circle --diameter D --cover C --tie T [--spacing S] [--ratio R]
```

- 간격이 있으면 간격으로 개수와 배치가 정해지고, 지름만 바뀌어 철근비가 달라진다. 간격이 없고 철근비만 있으면 개수도 철근비에 맞춰 고른다.
- 출력은 후보별 지름, 개수, 실제 철근비, 실제 간격, 순간격, TOML `bars` 이다. 순간격 경고와 철근비 범위 경고는 참고용이며 설계기준 원문과 대조하지 않았다.
- 후보 중 가까운 2~3개를 표로 **보여 준다**. 간격이나 철근비가 주어졌고 아래 기준에 맞는 후보가 있으면 **묻지 말고** 목표 철근비에 가장 가까운 후보를 자동 선택한다(철근비 목표가 없고 간격만 있으면 철근비 1~4% 안에서 지름이 가장 작은 후보, 동점이면 지름이 작은 것). 선택한 후보, 선택 이유, 목표와 실제 철근비의 차이를 숨기지 않고 ASSUMPTIONS 에 적는다. 간격도 철근비도 없거나 기준에 맞는 후보가 없을 때만 사용자에게 고르게 한다.
- **후보 고르는 기준**: 후보는 경고(순간격, 철근비 1~8% 밖)가 없고 철근비가 1~4% 인 것 중 지름이 작은 순서로 최대 3개 보여 준다. 사용자가 지름이나 철근비를 이미 말했으면 그 값을 우선한다. 철근비만 주어 첫 후보가 순간격 경고(예: 얇은 철근 다수)이면 그 후보는 빼고 보여 준다. 조건에 맞는 후보가 하나도 없으면 임의로 고르지 말고, 후보 전체와 이유를 보여 주고 사용자에게 지름, 간격, 철근비 중 무엇을 바꿀지 묻는다.
- 이 스크립트는 외곽 둘레 철근만 계산한다. 중간 열 철근이 필요하면 사용자에게 알리고 손으로 추가한다.

### 그 밖의 형상(T, L, 트랙, 중공, 임의 다각형)

스크립트가 없다. 같은 방식(표면에서 `순피복 + 띠철근 + 지름/2` 안쪽 위치, 간격으로 개수, 지름으로 철근비)으로 직접 계산하고, 철근 좌표를 표로 보여 준다. 경고가 없고 정보가 충분하면 승인을 받지 않고 그대로 쓴다. 변마다 `line` 생성자를 쓰고 모서리 철근이 두 번 들어가지 않게 한다. 중공 단면은 바깥면과 안쪽면 철근을 따로 묻는다.

**직접 계산한 배근도 layout.py 와 같은 검사를 반드시 한다.** 좌표표를 보여 주기 전에 다음을 계산해 표 아래에 적는다.

- 철근비 = 개수 x 철근 단면적 / 콘크리트 총단면적. 1~8% 밖이면 경고한다.
- 서로 이웃한 철근의 순간격(중심 간격 - 철근 지름) 최소값. `max(1.5 x 지름, 40 mm)` 보다 작으면 경고한다. 이 값은 설계기준 원문과 대조하지 않은 참고용이다.
- 경고가 하나라도 있으면 그대로 확정하지 말고, 지름 변경, 간격 조정, 일부 철근 생략 중 어떤 안이 좋은지 사용자에게 제안하고 승인받는다. 경고를 알린 뒤 사용자가 그대로 진행하겠다고 하면 진행하되 ASSUMPTIONS 에 경고를 적는다.
- 철근비 경고는 처음 제안하는 지름을 정할 때도 적용한다. 철근비 목표가 없을 때 기본 호칭 목록의 첫 항목(가장 가는 철근)을 그대로 제안하지 말고, 철근비가 1~4% 가 되는 지름 중에서 고른다.

계산한 개수와 철근비는 조각을 만든 뒤 `--summary` 의 `bars`, `rho` 와 대조하는 것은 `/biaxnm` 의 일이다.

## 4. 형강, PS강봉 (선택)

철근 정보를 받은 뒤 "단면에 매입 형강이나 PS강봉(긴장재)이 있습니까?"를 묻는다. 없다고 하면 넘어간다. 계산 없이 받은 값을 그대로 쓴다.

- **형강** (`[[section.steel]]`): 형상(`h_section`: d, bf, tw, tf / `hollow_rect`: width, height, t), 중심 위치(`cx`, `cy`), 형강 항복강도 `Fy`. 매입 형강은 보통 단면 중심이다.
- **PS강봉** (`tendons`): 배치(원 위 `circle = [cx, cy, 반지름]`, `n` 또는 개별 좌표), 1개 단면적 `area`, 유효 프리스트레스 `fse`(인장 +, MPa), 긴장재 항복강도 `fpy`. 탄성계수 `Ep` 는 사용자가 말했을 때만 쓴다.
- `Fy`, `fpy`, `Ep` 는 `[section]` 이 아니라 `[code]` 의 키이다. 조각 출력의 "code 에 더할 키"로 따로 낸다.
- 철근이 형강이나 구멍과 겹치면 프로그램이 오류를 낸다(`overlaps steel region` 등). 겹칠 수 있는 배치이면 철근을 형강 밖으로 옮기는 방안(간격 조정 등)을 사용자에게 제안하고 승인받는다.

## 5. 재계산 모드 (NG 일 때)

`/biaxnm` 이 현재 배근, 철근비, DCR 을 알려 주고 부른다. 단면 치수, 피복, 띠철근은 그대로 두고 아래만 바꾼다.

1. 사용자에게 무엇을 바꿀지 묻는다: **철근 직경**, **철근 간격**, **둘 다**. 
2. `layout.py` 를 새 값으로 다시 실행한다. 직경만 바꾸면 `--sizes` 를 현재보다 큰 호칭 위주로 주고 현재 `--spacing` 은 그대로 둔다. 간격만 바꾸면 현재 직경을 `--sizes` 에 주고 `--spacing` 을 줄인다(개수가 늘어난다). 처음에 간격 없이 철근비만 썼다면 새 목표 철근비를 사용자와 정해 `--ratio` 로 준다. 철근 중심 위치는 직경이 바뀌면 달라진다.
3. 후보를 현재 값과 나란히 보여 준다(직경, 개수, 철근비). 철근비가 1~8% 를 벗어나거나 순간격 경고가 있으면 함께 알린다. 사용자가 고르거나 수정하면 새 `bars` 조각을 낸다. 승인 없이 확정하지 않는다.
4. 이 모드에서는 `bars` 조각만 낸다.

DCR 이 크게 넘는데 철근비가 이미 상한 가까이이면, 철근만으로는 해결이 어려울 수 있다고 알리고 단면 치수 변경은 사용자의 판단이라고 말한다. 스스로 단면을 바꾸지 않는다.

## 6. 조각 출력

아래 형식의 코드 블록 하나와, 요청에 있던 값과 직접 계산한 값의 구분 목록(ASSUMPTIONS)을 낸다. 해석 옵션과 하중은 넣지 않는다.

```toml
[section]
outer = { shape = "rect", width = 400, height = 600 }
rebar_standard = "KS"
bars = [
  { line = [[61.1, 61.1], [338.9, 61.1]], n = 3, size = "D22" },   # 아래
]
# holes, [[section.steel]], tendons 는 있을 때만
```

`[[section.steel]]` 은 별도 표이므로 `[section]` 의 키(`outer`, `holes`, `bars`, `tendons` 등)를 모두 쓴 뒤에 둔다.

형강이나 PS강봉이 있으면 `[code]` 에 더할 키를 따로 낸다. `/biaxnm` 이 `[code]` 에 합친다.

```toml
# code 에 더할 키
Fy = 355      # 형강이 있을 때
fpy = 1275    # PS강봉이 있을 때
```

## 부록. [section] 스키마

`[section]` 에는 `outer`(필수), `holes`, `rebar_standard`, `bars`, `steel`, `tendons` 를 쓴다. 길이는 mm, 각도는 deg 이다.

### outer: 콘크리트 외곽선

다각형은 (a) 꼭짓점 목록 `[[x1, y1], [x2, y2], ...]`(3개 이상, 시계·반시계 모두 가능, 자기 교차 불가) 또는 (b) 도형 표 `{ shape = "...", ... }` 로 준다. 도형 `shape` 의 키(`outer`, `holes` 공통):

| shape | 필수 키 | 선택 키 (기본) |
|---|---|---|
| `rect` | width, height | x=0, y=0 (좌하단), r=0 (네 모서리 반지름), n_arc=12 (90도당 호 분할 수) |
| `circle` | r (반지름) | cx=0, cy=0 (중심), n=64 (다각형 꼭짓점 수), equal_area=false (true 면 면적이 pi·r² 가 되게 보정) |
| `track` | length (전체 길이), width (폭, 반원 지름), length > width | cx=0, cy=0, rotation_deg=0 (중심 둘레 반시계 회전), n_arc=12. 양쪽 반원 + 직선부(스타디움) |
| `t_section` | bf (플랜지 폭), h (전체 높이), tf (플랜지 두께), tw (웹 두께) | x=0, y=0 (외접 사각형 좌하단), rotation_deg=0. 플랜지가 위 |
| `l_section` | width, height (외곽), tx (세로 다리 폭), ty (가로 다리 높이) | x=0, y=0, r=0 (오목한 모서리 반지름), rotation_deg=0, n_arc=12. 세로 다리 왼쪽, 가로 다리 아래 |

### holes: 콘크리트 구멍

여러 개 가능. 외곽선 안쪽에 완전히 들어가야 하고 서로 겹치면 안 된다.

```toml
holes = [
  { shape = "circle", cx = 200, cy = 300, r = 50 },
  [[100, 100], [150, 100], [150, 150], [100, 150]],
]
```

### rebar_standard: 철근 규격표 (선택, 기본 "custom")

철근 1개의 단면적을 호칭(`size`)으로 줄 때 쓰는 표를 정한다.

| 값 | 표 | 호칭 |
|---|---|---|
| `custom` | 표를 쓰지 않음. `area` [mm²] 또는 `dia` [mm] 를 직접 줌 (기본) | |
| `KS` | KS D 3504 이형철근 | D4 D5 D6 D7 D8 D10 D13 D16 D19 D22 D25 D29 D32 D35 D38 D41 D43 D51 D57 (D25 = 506.7 mm², 공칭지름 25.4) |
| `ASTM` | ASTM A615 (인치-파운드 호칭) | #3 #4 #5 #6 #7 #8 #9 #10 #11 #14 #18, "8" 처럼 숫자만도 가능 (#8 = 509.7 mm²) |
| `ASTM_SI` | ASTM A615M (미터 호칭) | #10 #13 #16 #19 #22 #25 #29 #32 #36 #43 #57 (#25 = 510 mm², 규격이 mm² 값을 직접 정함) |
| `BS` | 공칭 지름 [mm] | 6 8 10 12 16 20 25 32 40 50, "T16", "H16", "B16" 도 가능 (16 = 201.1 mm², 6 과 50 은 규격표에서 비권장) |

KS 는 공칭지름의 원 면적 π/4·d², ASTM 은 규격의 in² 값, ASTM_SI 는 규격의 mm² 값, BS 는 π/4·d² 이다. 표 값은 KS D 3504 표 4, ASTM A615/A615M-12 표 1, BS 단면적 표와 대조했다.

### bars: 철근

항목 하나는 아래 형식 중 하나이고 목록 안에 섞어 써도 된다.

| 형식 | 의미 |
|---|---|
| `[x, y, area]` | 한 개 (area = 철근 1개 단면적 [mm²]) |
| `{ x = 60, y = 60, area = 507 }` | 한 개 (표 형식) |
| `{ x = 60, y = 60, size = "D25" }` | 규격 호칭으로 면적을 정함 (`rebar_standard` 필요) |
| `{ x = 60, y = 60, dia = 25.4 }` | 지름 [mm] 로 면적을 정함 (π/4·dia²). `rebar_standard` 와 무관 |
| `{ x = 60, y = 60, area = 507, law = { ... } }` | 이 철근만 다른 재료 곡선 (`biaxnm-inputs` 부록의 "재료 곡선" 형식) |
| `{ line = [[x1, y1], [x2, y2]], n = 4, area = 507 }` | 두 점 사이에 n 개를 등간격 배치 (양 끝점 포함, n=1 이면 중점) |
| `{ circle = [cx, cy, r], n = 12, area = 507, start_deg = 0 }` | 반지름 r 원 위에 n 개를 등간격 배치 (start_deg 에서 시작) |

면적은 `area`, `dia`, `size` 중 정확히 하나로 준다. `line` 과 `circle` 에도 같은 키와 `law` 를 줄 수 있다. 철근은 콘크리트 안(경계 포함)에 있어야 하고 구멍, 형강 안에 있으면 안 된다.

### steel: 매입 형강 (여러 개 가능, `[[section.steel]]` 로 하나씩)

```toml
[[section.steel]]
polygon = { shape = "h_section", d = 300, bf = 200, tw = 10, tf = 16, cx = 200, cy = 300 }
```

`polygon` 은 도형 표 또는 꼭짓점 목록 `[[x, y], ...]` 이다. 형강 도형:

| shape | 필수 키 | 선택 키 (기본) |
|---|---|---|
| `h_section` | d (전체 높이), bf (플랜지 폭), tw (웹 두께), tf (플랜지 두께) | cx=0, cy=0 (중심), rotation_deg=0, r=0 (웹-플랜지 모깎기), n_arc=8 |
| `hollow_rect` | width, height (외곽), t (벽 두께, 2t < 짧은 변) | cx=0, cy=0, rotation_deg=0. 속 빈 부분은 자동으로 구멍이 됨 |

선택 키: `holes`(형강 내부 구멍을 더 낼 때, 콘크리트 도형 또는 꼭짓점 목록), `law`(예: `{ type = "elastic_plastic", E = 200000, fy = 355 }`. 없으면 `[code]` 의 `Fy` 로 만든 탄소성 곡선).

### tendons: 긴장재 (bars 와 같은 형식 + 프리스트레스 키)

```toml
tendons = [
  { circle = [200, 300, 150], n = 8, area = 98.7, fse = 1000 },
  { x = 100, y = 100, area = 98.7, fse = 1000 },
]
```

| 키 | 의미 |
|---|---|
| `area` | 긴장재 1개 단면적 [mm²] |
| `fse` | 유효 프리스트레스 [MPa], 인장을 양수로 입력 (기본 0) |
| `eps_pe` | `fse` 대신 프리스트레인(인장 변형률)을 직접 줄 때 (`fse` 보다 우선) |
| `duct_area` | 덕트 단면적 Apd [mm²] (선택). 콘크리트에서 이 면적만큼 뺀다. 없으면 area 와 같다(Apd = Apt). 덕트가 없는 프리텐션은 0 (ACI 22.4.2.3 의 Apd) |
| `law` | 이 긴장재만 다른 곡선 |
