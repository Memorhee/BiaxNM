# BiaxNM 입력 파일 작성과 계산

`biaxnm-inputs`, `biaxnm-section` skill 을 차례로 실행해 TOML 조각을 모으고 합쳐 계산하는 오케스트레이션 skill 이다. 직접 TOML 을 설계하지 않는다. 사용자와 같은 대화 안에서 실행되므로 필요하면 질문할 수 있지만, **입력 정보가 충분하면 질문과 승인 없이 끝까지 자동으로 실행한다**(아래 "자동 진행 원칙").

## 지켜야 할 것

- **모든 대화는 무조건 한국어로 한다.** 사용자가 다른 언어로 말하거나 영어 용어를 써도 질문, 확인 표, 보고, 오류 설명을 모두 한국어로 쓴다. 프로그램 출력, 오류 문장, TOML 키, 파일 경로처럼 그대로 보여 줘야 하는 원문만 원래 언어로 두고 필요하면 한국어 설명을 붙인다. 이 규칙은 이 skill 이 부르는 `biaxnm-inputs`, `biaxnm-section` 단계에도 적용된다.
- **자동 진행 원칙**: 정보가 충분하면 값을 표로 출력만 하고 응답을 기다리지 않는다. 확인 질문, 후보 선택 질문, 계산 승인 질문을 하지 않는다. 아래 경우에만 멈추고 묻는다: (1) 필수 정보가 빠졌거나 모호하다, (2) 허용 범위를 벗어난 값이나 입력 오류(철근이 단면 밖이거나 형강과 겹침 등)로 임의로 정할 수 없다, (3) 순간격·철근비 경고가 있는데 조건에 맞는 후보가 없다, (4) 사용자가 "확인 후 계산"이라고 요청했다, (5) DCR 이 1을 넘어 입력을 바꿔야 한다. 자동으로 정한 값(기본값, 자동 선택한 배근 등)은 모두 ASSUMPTIONS 에 적어 보고한다.
- 설계 판단을 하지 않는다. 입력에 없는 강도, 치수, 배근, 하중, 설계기준을 추측하지 않는다. 빠진 값은 skill 이 사용자에게 묻는다.
- 쓰는 곳은 `out/<이름>/` 뿐이다(입력 TOML `NAME.toml`, 단면 미리보기 그림 `NAME_section.png`, 계산 결과가 모두 이 폴더에 모인다). `src/`, `examples/*.toml`, 테스트, 문서를 수정하지 않는다. 계산이 이상해 보여도 프로그램 코드를 고치려 하지 말고 사용자에게 보고한다.
- DCR 이 1을 넘어도 사용자 승인 없이 입력을 바꾸지 않는다.
- 명령은 `<PY>` 로 쓴다. 저장소에 `python/python.exe` 가 있으면 그것을, 없으면 `python` 을 쓴다. 필요한 패키지는 numpy, scipy, matplotlib 이다. 명령이 실패하면 오류 문장을 그대로 사용자에게 보여 준다.

## 1. 호출 받기

사용자가 정보 없이 불렀으면 "어떤 단면을 검토할까요?"라고 묻고 자유 서술을 받는다. 정보를 주며 불렀으면 그 문장을 쓴다.

## 2. 주어진 정보로 TOML 을 완성할 수 있는지 확인

받은 문장에서 값을 뽑아 체크리스트를 채운다. 채우지 못한 항목을 **부족한 정보 목록**으로 만든다. 목록이 비어 있으면(정보가 충분하면) 채운 값을 표로 **출력만** 하고 질문 없이 3단계로 넘어간다. 목록이 있으면 부족한 항목만 묻는다(채워진 값은 표로 보여 주기만 한다).

| 구분 | 항목 |
|---|---|
| 설계기준·재료 | 설계기준 type, 콘크리트 강도(`fc`/`fck`), 철근 `fy`, 횡철근 형식(`aci318-25`, `kds14-22` 만) |
| 하중 | 하중 이름, `Pu`, `Mux`, `Muy` 와 단위. 곡선만 원하면 `lambda_u_deg` |
| 콘크리트 단면 | typical 여부, 도형과 치수 |
| 철근 | 순피복, 띠철근 직경, 철근 간격과 철근비(둘 중 하나 이상), 규격표 |
| 선택 | 형강(H형, 중공 사각), PS강봉(긴장재) 유무 |

사용자가 준 값은 다시 묻지 않는다.

**사용자가 "모름" 이라고 답했을 때** 아래 기본값만 쓴다. 이 목록에 없는 항목(강도, 치수, 배근, 하중 값, 설계기준)은 기본값이 없으므로 계속 묻는다. 기본값을 쓰면 확인 표와 ASSUMPTIONS 에 "모름 -> 기본값" 으로 적는다.

| 항목 | 기본값 |
|---|---|
| 하중 이름 | `L1`, `L2`, ... (요청 순서) |
| 하중 단위 | kN, kN·m (프로그램 고정 단위, 다른 단위는 환산) |
| 형강, PS강봉 유무 | 없음 |
| 모멘트 기준점 | `geometric` (입력한 Mux, Muy 가 콘크리트 총단면 도심 기준이어야 한다고 한 줄로 알린다) |

## 3. 단면 정보를 제외한 나머지: `biaxnm-inputs`

Skill 도구로 `biaxnm-inputs` 를 실행한다. 이미 아는 값과 부족한 항목 목록을 함께 알려서, 부족한 것만 묻고 `[code]`, `[analysis]`, `[loads]` 조각을 채우게 한다. 부족한 항목이 없으면 "질문하지 말고 조각만 내라"고 알린다.

## 4. 단면: `biaxnm-section`

Skill 도구로 `biaxnm-section` 을 실행한다. 이미 아는 값을 알려 준다. 이 skill 이 콘크리트 단면 치수와 철근 정보(순피복, 띠철근, 간격, 철근비) 중 부족한 것만 묻고 배근 후보를 계산한다. 정보가 충분하면 질문 없이 후보 중 하나를 자동 선택해 조각을 낸다. 형강과 PS강봉 유무는 요청에 없을 때만 묻는다. 결과는 `[section]` 조각, 그리고 형강이나 PS강봉이 있으면 `[code]` 에 더할 키(`Fy`, `fpy`, 선택으로 `Ep`)다.

## 5. TOML 만들기

`out/<짧은_이름>/<짧은_이름>.toml` 에 쓴다(`NAME` 은 이 짧은 이름이다). 폴더가 없으면 만든다. 같은 이름의 폴더가 있으면 덮어쓰지 말고 `_2`, `_3` 을 붙인다. 프로그램의 기본 출력 폴더가 `out/<파일 이름>/` 이라 계산 결과도 같은 폴더에 저장된다. 순서는 `[code]`(4단계의 `Fy`, `fpy` 를 여기에 더한다), `[section]`(`[[section.steel]]` 포함), `[analysis]`, `[loads.*]` 이다. 첫 줄 주석에 원문 요청을 적고, 요청에 있던 값과 직접 계산한 값을 구분한다. BOM 없는 UTF-8 로 쓴다.

## 6. 검증, 작도 전 출력, 실행

### 6-1. 입력 검증

```
<PY> src/main.py out/NAME/NAME.toml --summary
<PY> .claude/skills/biaxnm/preview.py out/NAME/NAME.toml
```

- 종료 코드 2 와 `error: section.bars[2]: ...` 는 입력 오류다. 위치를 보고 고쳐서 다시 실행한다. 최대 3회 시도하고, 그래도 안 되면 오류 문장을 보여 주고 사용자에게 어떻게 할지 묻는다. 철근이 단면 밖이거나 형강과 겹치는 등 입력 자체가 모순이면 좌표를 임의로 옮기지 말고 묻는다.
- `--summary` 의 콘크리트 면적, 철근 개수와 총면적, 철근비, 하중을 사용자가 승인한 값과 대조한다. 어긋나면 파일을 고친다.
- `preview.py` 는 해석 없이 단면 그림 `out/NAME/NAME_section.png` 를 만들고 그 경로를 출력한다.

### 6-2. 작도 직전 검토 조건 출력 (생략 금지, 승인은 받지 않는다)

PM 상관도를 계산·작도하기 전에, 아래 내용을 **대화창에 직접** 출력한다. 재계산(7단계) 때도 바뀐 배근으로 다시 출력한다.

1. **단면 그림**: `NAME_section.png` 를 Read 도구로 열어 대화에 보이고, SendUserFile(`display: "render"`)로 사용자에게도 보낸다. 그림을 못 만들었으면 그 이유를 적고 아래 표로 대신한다.
2. **검토 조건 표** (한국어, 단위 포함):

| 구분 | 내용 |
|---|---|
| 입력 파일 | `out/NAME/NAME.toml` |
| 설계기준 | type, 횡철근 형식 |
| 재료 | fc(fck), fy, (형강 Fy, 긴장재 fpy) |
| 콘크리트 단면 | 도형, 치수, 면적(`--summary` 값) |
| 철근 | 규격·개수, 총면적, 철근비, 순피복, 띠철근 직경, 간격 |
| 형강 / 긴장재 | 있으면 규격과 위치, 없으면 "없음" |
| 해석 옵션 | 모멘트 기준점, lambda_u_deg 등 `[analysis]` 값 |
| 하중 | 하중별 Pu [kN], Mux, Muy [kN·m] |
| 가정 | "모름 -> 기본값" 등 직접 정하거나 환산한 값 |

3. 출력한 뒤 **응답을 기다리지 않고 바로 6-3 을 실행한다.** 사용자가 처음에 "확인 후 계산"이라고 요청했거나, 6-1 에서 입력 오류·경고가 남아 있으면 "이 조건으로 PM 상관도를 계산할까요?" 라고 묻고(AskUserQuestion: **계산 진행** / **조건 수정**) 승인 전에는 6-3 을 실행하지 않는다. 수정을 요청하면 해당 skill(`biaxnm-inputs` 또는 `biaxnm-section`)로 돌아가 고치고 6-1 부터 다시 한다.

### 6-3. 실행

```
<PY> src/main.py out/NAME/NAME.toml
```

- 실행 출력의 하중별 `DCR = ... (OK/NG)` 를 읽는다.

## 7. OK / NG 판정과 재계산

결과를 하중별 DCR 표로 보여 준다. 하중 중 하나라도 NG 이면(DCR > 1):

1. 사용자에게 묻는다: **철근 직경 변경**, **철근 간격 조정**, **둘 다**, **그대로 종료**.
2. 직경 변경이나 간격 조정이면 `biaxnm-section` 을 재계산 모드로 실행한다(현재 배근, 현재 DCR 과 철근비를 알려 준다). 단면 치수, 재료, 하중은 바꾸지 않는다.
3. 사용자가 후보를 승인하면 같은 파일의 `bars` 만 고쳐 쓴다. 승인 없이 바꾸지 않는다.
4. 6단계로 돌아가 다시 검증하고, 6-2 의 단면 그림과 검토 조건을 출력한 뒤 바로 실행한다(6-2 의 3번 예외 제외).

OK 이면 재계산하지 않고 보고로 넘어간다. 반복마다 (회차, 배근, 철근비, DCR) 를 표에 쌓는다.

## 8. 보고

보고 내용(한국어):

- 파일 경로(`out/NAME/NAME.toml`)
- `--summary` 출력
- ASSUMPTIONS: 직접 계산했거나 환산한 값(두 skill 의 것을 합친다)
- 결과: 하중별 DCR 과 OK/NG, lambda_u, P0, 출력 폴더. 재계산했다면 회차별 표
- 주의: 이 프로그램은 검증 중이므로 입력과 결과를 설계기준 원문과 독립 계산으로 확인해야 한다.
